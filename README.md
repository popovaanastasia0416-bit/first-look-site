# FIRST LOOK — агентство ИИ-моделей

Многостраничный сайт по структуре models1.co.uk: главная с видео, доски «женщины» и «мужчины» (фильтры, наведение с параметрами), 16 страниц моделей, услуги, видео, агентство, заявка, контакты, избранное, поиск. Русская версия в корне, английская — в `/en/`.

Сборка: `python src/build.py` (тексты — `src/content.py` и `src/data.py`). Фото — `src/prep_assets.py`, видео — `src/prep_video.py`. Прежний лендинг — `src/build_landing_old.py`.
